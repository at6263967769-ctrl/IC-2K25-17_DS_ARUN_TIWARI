## ⏱️ Asymptotic Complexity Matrix

| Data Structure / Algorithm | Access / Search | Insertion | Deletion | Space Complexity |
| :--- | :--- | :--- | :--- | :--- |
| **Array** | $O(1)$ | $O(n)$ | $O(n)$ | $O(n)$ |
| **Singly Linked List** | $O(n)$ | $O(1)$ (head) / $O(n)$ | $O(1)$ (head) / $O(n)$ | $O(n)$ |
| **Doubly Linked List** | $O(n)$ | $O(1)$ | $O(1)$ | $O(n)$ |
| **Stack (Array/List)** | $O(n)$ / $O(1)$ top | $O(1)$ (push) | $O(1)$ (pop) | $O(n)$ |
| **Queue (Circular)** | $O(1)$ front | $O(1)$ (enqueue) | $O(1)$ (dequeue) | $O(n)$ |
| **Binary Search Tree** | $O(\log n)$ avg / $O(n)$ worst | $O(\log n)$ avg / $O(n)$ worst | $O(\log n)$ avg / $O(n)$ worst | $O(n)$ |
| **AVL Tree** | $O(\log n)$ | $O(\log n)$ | $O(\log n)$ | $O(n)$ |

| Algorithm | Best Case | Average Case | Worst Case | Space Complexity | Stability |
| :--- | :--- | :--- | :--- | :--- | :--- |

| **Heap Sort** | $O(n \log n)$ | $O(n \log n)$ | $O(n \log n)$ | $O(1)$ | No |

## 🛠️ Build and Execution Guide

### Prerequisites

Ensure you have a modern C++ compiler installed:
- GCC / G++ (v9.0 or higher) or Clang (v10.0 or higher)
- Optional: Make or CMake

Check your compiler version:
```bash
g++ --version
```

### Compiling and Running a Module

1. Clone the repository:
   ```bash
   git clone https://github.com/at6263967769-ctrl/IC-2K25-17_DS_ARUN_TIWARI.git
   cd IC-2K25-17_DS_ARUN_TIWARI
   ```

2. Compile any program with standard optimization and debugging flags:
   ```bash
   g++ -std=c++17 -Wall -Wextra -O2 02_Linked_Lists/singly_linked_list.cpp -o singly_linked_list
   ```

3. Execute the binary:
   ```bash
   ./singly_linked_list
   ```
